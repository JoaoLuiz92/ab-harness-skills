# Workflow core

1. Read `workflow.config.md` at repo root.
2. Read `.specs/quick/CURRENT-FOCUS.md` first.
3. Skim `.specs/codebase/DISCOVERY.md` and `.specs/project/PROJECT.md`.
4. Read `.specs/quick/NEXT-ACTIONS.md` (canonical) or `docs/workflow/next_actions.md` when `JIRA_TASKS=OFF`.
5. Follow `docs/workflow/test-lane.md` when closing code deliveries.

Implementer does not run formal validation lane as self-gate.
